02 / HOW TO USE

Run a demonstration

  1. Open the performance calculator and select an aircraft card.
  2. Confirm that the example aircraft values appear in the model inputs.
  3. Set a speed range and select Calculate performance to display results.
  4. Use Download CSV to export the displayed table.

Safety note: This school-project calculator is not validated for flight planning, aircraft operation, or real performance decisions. Never use its output operationally.
